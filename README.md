# YouTube Clone

A frontend practice project recreating the layout and user interface of YouTube using **HTML5** and **CSS3**.

## 📖 Description

This project is a static clone of the YouTube website, built as part of my journey to learn and practice frontend web development. The goal is to replicate YouTube's core layout and design — including the header, sidebar, video grid, and other UI elements — using only HTML and CSS.

This is a **learning project** and is **not affiliated with, endorsed by, or connected to YouTube or Google** in any way.

## ✨ Features

- Responsive header with logo, search bar, and icons
- Collapsible sidebar navigation
- Video grid layout with thumbnails, titles, and channel info
- Category filter chips/buttons
- Clean and modern UI inspired by YouTube
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- **HTML5** – Semantic page structure
- **CSS3** – Styling, layouts, and responsiveness
  - Flexbox
  - CSS Grid
  - Positioning
  - Media queries

## 📚 What I Learned

- Structuring a complex webpage using semantic HTML5
- Building responsive layouts with Flexbox and CSS Grid
- Working with positioning (relative, absolute, fixed, sticky)
- Styling reusable components like buttons, cards, and icons
- Creating a mobile-friendly, responsive design
- Organizing CSS for readability and maintainability

## 🚀 How to Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/calligraphyguruji/YouTube-Clone.git
   ```
2. Navigate to the project folder
   ```bash
   cd YouTube-Clone
   ```
3. Open `index.html` in your browser
   - Simply double-click the file, or
   - Use the **Live Server** extension in VS Code for a better experience

No installations or dependencies required — this is a pure HTML/CSS project.
